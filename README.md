# quotes.tera-services — منصة تيرا (معاينة الواجهات)

واجهات منصة تيرا للخدمات المتكاملة: الموقع العام، وبوابة الدخول، ومنصة العملاء، ومنصة الموظفين — منظّمة في مجلدات مستقلة تعمل مباشرة على GitHub Pages.

> هذا المستودع هو **المصدر الوحيد** لمنصة تيرا: يُنشر تلقائيًا إلى منفذ الاختبار staging.tera-services.com.sa ويعمل هناك ببيانات حقيقية، ومنه يُنشر المنفذ الرئيسي بوسم ثابت. المعاينة التفاعلية ببيانات تجريبية في المستودع العام msjtr/quotes-preview.
>
> **حالة المنصة والتسليم والمزوّدين والمفاتيح والمنافذ والمشكلات المفتوحة:** [`docs/HANDOFF.md`](docs/HANDOFF.md) — المرجع المعتمد الوحيد.

## الأقسام

| المجلد | القسم | المحتوى |
|---|---|---|
| `home/` | الرئيسية | الموقع العام وكل صفحاته: الخدمات، المتجر وسوق الأجهزة، المنتجات، العضويات، الأسئلة الشائعة، مركز المراسلات، السياسات |
| `portal/` | البوابة | تسجيل الدخول، إنشاء الحساب (6 خطوات)، التحقق من البريد والجوال وواتساب، المصادقة الثنائية (تطبيق المصادقة / الرمز الإضافي)، توثيق الأجهزة، نسيت كلمة المرور، رموز الاستعادة |
| `clients/` | العملاء | لوحتي الرئيسية، ملفي الشخصي، مركز الأمان، الطلبات والعروض والدفعات، العضوية والنقاط، المتجر ومختاراتي، المراسلات والإشعارات |
| `staff/` | الموظفين | لوحة المشرف والموظف بستة أقسام: الرئيسية · العملاء · المالية · التواصل · الفريق والشركاء · الإعدادات |
| `index.html` | الكل | المعاينة الشاملة بشريط العرض (الرئيسية · البوابة · المنصة، العميل · المشرف، ويب · جوال) |

## البنية

```
├─ index.html            المعاينة الشاملة
├─ home/ portal/ clients/ staff/   مدخل لكل قسم (index.html)
├─ assets/
│  ├─ css/   base.css · platform.css (هوية المنصة) · preview.css (شريط العرض وشاشة الانتظار)
│  ├─ js/    platform.js (محرك منصة العملاء والموظفين) · site-runtime.js (عارض الموقع والبوابة) · dev-toggle.js
│  ├─ site/  core.js — بيانات الموقع والبوابة مضغوطة (تُولَّد من src/site)
│  ├─ pp/    بيانات صفحات المنتجات مقسّمة حسب الفئة
│  ├─ vid/   الفيديوهات وصورها الافتتاحية وطبقات الشعار المتحرك وصور تطبيقات المصادقة
│  └─ hi/ si/ pimg2/ dimg/   صور المنتجات والواجهات
├─ src/
│  ├─ site/   مولّد الموقع والبوابة (Python): pages*.py · store.py · build2.py · ts.js · portal.js · site.css · parent2.js
│  └─ video/  مولّدات الفيديو (Playwright + ffmpeg): vgen2.html · hero2.html · rgen2.js · hgen.js · film2*.js
├─ tests/    اختبارات المسارات (Playwright): البوابة، الوظائف، شاشة الانتظار، المداخل
└─ tools/build.py   استيراد المعاينة، وتوليد المداخل، وإعادة التجميع في ملف واحد
```

كل مدخل يستخدم `<base href="../assets/">`، فتبقى المسارات داخل الأصول واحدة لكل الأقسام.

## التشغيل محليًا

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080/  أو  /home/ · /portal/ · /clients/ · /staff/
```

## التحديث

```bash
# 1) بعد تحديث المعاينة الموحّدة (sample.html) ومجلد الوسائط:
python3 tools/build.py import <sample.html> <media_dir> src/site
# 2) توليد صفحات الأقسام:
python3 tools/build.py entries
# 3) (اختياري) ملف واحد مكافئ للنشر كمعاينة:
python3 tools/build.py bundle dist/preview.html
```

## القواعد الثابتة للواجهة

- فاتح/ليلي بألوان مطابقة لا معكوسة، ويب وتطبيق جوال، هوية TERA، أرقام لاتينية.
- القوائم المنسدلة للاختيارات، والمصطلحات «دفعة/منتج».
- مقياس المسافات: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64.
- شاشة الانتظار تظهر في كل تحميل وانتقال وتحديث، 3 ثوانٍ على الأقل.
- البوابة: مدة الجلسة والخمول من «سياسة الجلسة» في الإعدادات، والمصادقة الثنائية اختيارية للعميل، ولا سؤال تصريح للجهاز للعميل بعد الدخول.

## ملاحظات

- صور تطبيقَي Google Authenticator وMicrosoft Authenticator من لقطات آيفون، واستُبدلت فيها بيانات الحساب والرمز ببيانات معاينة.
- مولّد `src/site` يقرأ مسارات بيانات المصدر من `lib.py` (المتغير `SP`)؛ عدّلها قبل التشغيل على جهاز آخر.
